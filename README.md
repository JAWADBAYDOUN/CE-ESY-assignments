# حل واجب لغة C - المخزن الدائري (Circular Buffer)

هذا المستودع يحتوي على حل الواجب الأول للمادة. 

## محتويات الحل (Assignment1):
* **prog.c**: ملف الكود المصدري الذي يحتوي على تنفيذ هيكل بيانات المخزن الدائري بلغة C.

## فكرة الكود:
يقوم البرنامج بتنفيذ مخزن دائري يدوياً (بدون استخدام مكتبات جاهزة) معتمداً على منطق "باقي القسمة" (%) لتحريك مؤشري القراءة والكتابة (Head & Tail) بشكل دائري.
البرنامج يقوم بالآتي:
1. تهيئة المخزن وتصفير العدادات.
2. طلب اسم المستخدم ودمجه مع النص `CE-ESY`.
3. إدخال السلسلة النصية حرفاً بحرف إلى المخزن مع فحص حالة الامتلاء (Overflow).
4. قراءة الحروف من المخزن وطباعتها على الشاشة مع فحص حالة الفراغ (Underflow).
